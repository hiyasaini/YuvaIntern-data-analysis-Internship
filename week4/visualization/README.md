# Week 4 – Visualizations

This folder contains the visualizations created during the Week 4 machine learning analysis. The plots are used to understand the dataset, evaluate classification performance, compare the machine learning models, and interpret the most important features.

The visualizations include the class distribution of the dataset, confusion matrices for Logistic Regression, Decision Tree and Random Forest, a comparison of model accuracy, and the top feature importances obtained from the Random Forest model.

These visualizations provide graphical support for the results discussed in the Week 4 notebook and report.
