# Week 4 – Machine Learning Classification

Week 4 focused on applying machine learning techniques to the Breast Cancer Wisconsin Diagnostic Dataset. The objective was to develop classification models capable of predicting whether a tumor is benign or malignant based on its characteristics.

The cleaned dataset from Week 1 was reused to maintain continuity throughout the internship. Data preprocessing, feature-target separation, train-test splitting, and feature scaling were performed before model training.

Three supervised machine learning algorithms were implemented: Logistic Regression, Decision Tree, and Random Forest. The models were evaluated using accuracy, precision, recall, F1-score, and confusion matrices. Their performance was compared to identify the most effective model for the classification task.

Random Forest feature importance was also analyzed to identify the tumor characteristics that contributed most to the model's predictions.

### Key Topics Covered

- Data preprocessing
- Feature and target selection
- Train-test split
- Feature scaling
- Logistic Regression
- Decision Tree
- Random Forest
- Model evaluation
- Confusion matrix
- Accuracy, precision, recall and F1-score
- Feature importance

### Tools Used

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn and Jupyter Notebook.
